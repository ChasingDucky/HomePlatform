## 1. 设计原则

### 1.1 核心设计理念

**Make Smart Home Simple**

我们的设计遵循三个核心原则：

#### 1. 简洁 (Simplicity)
- 界面简洁清晰，减少视觉噪音
- 操作流程简单直观，降低学习成本
- 信息层级分明，突出重点

#### 2. 智能 (Intelligence)
- AI 主动推荐，减少用户操作
- 智能预测用户需求
- 上下文感知，适时提供帮助

#### 3. 可靠 (Reliability)
- 稳定的性能表现
- 清晰的状态反馈
- 可预测的交互结果

## 4. 字体排版

### 4.1 字体家族

#### 中文字体

```
Primary: PingFang SC (苹方)
Fallback: Microsoft YaHei (微软雅黑), sans-serif
```

#### 英文/数字字体

```
Primary: Inter, -apple-system, BlinkMacSystemFont, sans-serif
Fallback: Helvetica Neue, Arial, sans-serif
```

#### 等宽字体 (代码/数据)

```
Monospace: SF Mono, Consolas, Monaco, monospace
```

---

### 4.2 字体大小

| 级别 | 大小 | 行高 | 用途 |
|-----|------|------|------|
| **H1** | 32px / 2rem | 40px | 页面主标题 |
| **H2** | 24px / 1.5rem | 32px | 区块标题 |
| **H3** | 20px / 1.25rem | 28px | 卡片标题 |
| **H4** | 18px / 1.125rem | 24px | 列表标题 |
| **Body Large** | 16px / 1rem | 24px | 主要内容 |
| **Body** | 14px / 0.875rem | 20px | 正文、按钮 |
| **Body Small** | 13px / 0.8125rem | 18px | 辅助文本 |
| **Caption** | 12px / 0.75rem | 16px | 说明文字 |
| **Tiny** | 11px / 0.6875rem | 14px | 极小文字 |

---

### 4.3 字重 (Font Weight)

```
Regular   (400) - 正文
Medium    (500) - 强调文本
Semibold  (600) - 次要标题
Bold      (700) - 主要标题
```

---

### 4.4 排版示例


## 11. 动画效果

```typescript
const easings = {

  easeOut: 'cubic-bezier(0, 0, 0.2, 1)',

};
```

---

### 11.2 动画时长

```
超快   50ms  - 开关切换
快     100ms - 悬停效果
正常   200ms - 标准过渡
慢     300ms - 页面切换
超慢   500ms - 复杂动画
```

---

### 11.3 常用动画

#### Fade In/Out

```css
@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

animation: fadeIn 200ms ease-out;
```

#### Slide Up

```css
@keyframes slideUp {
  from { transform: translateY(20px); opacity: 0; }
  to { transform: translateY(0); opacity: 1; }
}

animation: slideUp 300ms ease-out;
```

#### Scale

```css
@keyframes scale {
  from { transform: scale(0.95); opacity: 0; }
  to { transform: scale(1); opacity: 1; }
}

animation: scale 200ms ease-out;
```
